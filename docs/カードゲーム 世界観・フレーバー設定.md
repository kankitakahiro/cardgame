各色のゲーム上の役割・キーワードは[game-rules-minimum.md](game-rules-minimum.md)
「色ガイド」、キーワードの定義は[keywords.md](keywords.md)を参照。ここでの

## ゲームの骨格

五つの色はそれぞれ独立した世界を持つ。ある日、そのどれにも属さない六番目の世界「第六界《ヘクサ》」が現れ、五つの世界がその荒野をめぐって争う。これがこのカードゲームの物語である。

| 色 | 世界 | ゲーム上の役割 | ヘクサへの動機 |
| --- | --- | --- | --- |
| 赤 | 決闘の国 | 速攻・バーン | まだ見ぬ強敵と黒い鉄 |
| 青 | 書庫と学生の国 | ドロー・除去 | まだ知らない知識の探求 |
| 橙 | 金砂の海を渡る商船の世界 | マーケット購入 | 初めての港、五つの世界をつなぐ市場、資源の独占 |
| 緑 | 世界樹を崇拝する使徒たちの国 | ユニット展開 | 灰の地に世界樹の種を植える |
| 紫 | 装いが力になる宮廷 | バフ・変貌 | 空位の王座 |

## 舞台：第六界《ヘクサ》

どの色にも属さない、無機質な灰色の荒野。草も水もなく、生き物の気配がない。名前の「ヘクサ」は六角形の結晶ともつながり、カード枠やアイコンなどのデザインにも展開できる。

### 荒野の姿

- 扉も窓もない四角い石の廃墟が等間隔に並ぶ。入口が見つかった例はない
- 廃墟の隙間から、黒い鉄の柱が地面を突き破って伸びている
- 柱や廃墟の角には、色のない透明な結晶が生えている。触れると冷たく、何も映さない
- 風が結晶の間を抜けるとき、かすかに金属を打つような音が鳴る。それがこの荒野で聞こえる唯一の音

### あえて残している謎

- 廃墟を造ったのは誰か。そもそも「造られた」ものなのか
- 結晶は今も少しずつ増えている。何を糧に育っているのか
- 第六界はなぜ突然現れたのか
- 廃墟の奥から夜ごと聞こえる刃を打ち合う音の主は誰か（赤の動機と連動）

### ゲームとの対応

- 対戦：色のない荒野に自分の世界の者を送り込み、拠点を築く争い
- マーケット：各世界が持ち込み置き去りにしたものが荒野に転がり、拾った者のものになる場所

### フレーバー例

- 「扉のない建物が千並んでいる。数えた者はいない。数えている間に、一つ増えるからだ。」
- 「結晶は何も映さない。覗き込んだ者の顔さえも。」
- 「この地で鳴る音は、風と、鉄と、自分の足音だけ。」

## 赤：決闘の国

あらゆる争いを一撃の決闘で決める国。ゲーム上の役割は速攻・バーン。

### 骨子

- 赤い岩肌の大地に、無数の決闘場が点在する。土地、財産、婚姻、法の解釈まで、すべて一対一の決闘で決める
- 決闘は一撃で終わるのが美徳。二太刀目を振るうのは恥とされ、誰もが「先に抜く」ことだけを磨き続ける
- 刃は抜く速さで赤熱する。達人が抜いた刃は炎をまとい、届かない距離の相手まで焼く
- 決闘には必ず立会人がつき、勝者の言葉がその場で掟になる
- 速攻＝先に抜く、バーン＝赤熱した刃の一閃が遠くの相手を焼く

### ヘクサへの動機

ヘクサの廃墟の奥から、夜ごと刃を打ち合う音が聞こえる。音の主を見た者はいないが、その刃は黒い鉄で鍛えられ、抜いた瞬間に誰よりも速く赤熱するという。

剣士たちは、見えない強敵と立ち合うこと、そしてその黒い鉄で自分だけの一振りを鍛えることを胸に荒野へ向かう。音の主の正体はあえて決めていない。

### カード例

| 種類 | カード名 | フレーバーテキスト |
| --- | --- | --- |
| ユニット | 抜き打ちの若武者 | 師匠は言った。考えるより先に、手が動くようになれと。 |
| ユニット | 立会人 | どちらが正しいかは知らない。どちらが立っていたかは覚えている。 |
| ユニット | 一太刀の剣聖 | 生涯で一度も、二太刀目を振るったことがない。 |
| ユニット | 音を追う剣士 | 夜になると、また聞こえる。あれは俺を呼んでいる。 |
| ユニット | 黒鉄の刀鍛冶 | この鉄は、打つたびに熱くなる。まるで早く抜かれたがっているようだ。 |
| スペル（速攻） | 先の先 | 相手が抜こうと思った瞬間、もう終わっている。 |
| スペル（速攻） | 黒鉄の抜き打ち | 刃が熱を帯びるより先に、もう斬っていた。 |
| スペル（バーン） | 赤熱の一閃 | 刃は届かなかった。炎だけが届いた。 |
| スペル | 決闘状 | 受け取った時点で、逃げ道はもうない。 |
| スペル | 廃墟の剣戟 | 打ち合う音が一つ増えた。誰かが、あの相手に辿り着いたらしい。 |

## 青：書庫と学生の国

巨大な書庫を中心に学生が多く暮らす国。ゲーム上の役割はドロー・除去。

### 骨子

- 国土の大半が書架で埋まった、巨大な書庫を中心とする国。住人には学生が多く、書庫の周りに学舎と寮が連なっている
- 身分は「どれだけ学んだか」で決まる。学位を重ねた者ほど敬われ、学ぼうとしない者は身分が低く、さげすまれる
- 卒業できるのは、書庫にまだ記されていない事柄を解き明かし、新しい一冊を書き上げた者だけ
- ドロー＝本を開いて学ぶ、調べる。除去＝書物に記された術で相手を封じる、弱点を調べ上げて退ける

### ヘクサへの動機

まだ知らない知識の探求。書庫のどの本にも、ヘクサについては一行も書かれていない。扉のない廃墟、何も映さない結晶、突然現れた理由。すべてが未知の荒野に、学生も学者も惹きつけられている。

### カード例

| 種類 | カード名 | フレーバーテキスト |
| --- | --- | --- |
| ユニット | 一年生の書架番 | どの棚に何があるか、まだ半分も覚えていません。棚は毎日増えるので。 |
| ユニット | 万年七年生 | 卒業しないんじゃない。書くべき一冊が、まだ見つからないだけだ。 |
| ユニット | 荒野の記録係 | ヘクサの頁は、まだ一枚目の一行目だ。 |
| スペル（ドロー） | 調べ物 | 答えはどこかの棚にある。問題は、それがどの棚かだ。 |
| スペル（除去） | 封書の術 | この頁に閉じ込めておきます。読み返すつもりはありません。 |
| スペル（除去） | 弱点の考察 | あなたのことは、もう三冊分調べてあります。 |

## 橙：金砂の海を渡る商船の世界

陸地のない金色の砂の海を、商船が行き交う世界。ゲーム上の役割はマーケット購入。

### 骨子

- 陸地が一つもなく、見渡す限り金色の砂の海が広がる。砂は風で絶えず流れ、同じ地形は二度と現れない
- 人々は砂の上を滑る商船に住み、船同士が連なって「船団都市」を作る。港も国もなく、船団そのものが国
- 値の付かないものは存在しないとされ、物だけでなく、情報、約束、航路、風向きまで取引される
- 船の大きさと積荷の量が、そのまま身分の高さになる
- マーケット購入＝積荷を買い付けて船団に加える

### ヘクサへの動機

砂の海の民は、流れない大地に一度も立ったことがない。ヘクサは生まれて初めて見る「動かない土地」であり、そこに港を築けば、何世代も漂い続けた船団がようやく錨を下ろせる。

しかもヘクサには五つの世界すべてから人と物が流れ込む。港に市場を開けば五つの世界の交易を握れる。剣士が求める黒い鉄も、学生が求める結晶も、先に押さえれば値を決めるのは橙になる。悲願の港、世界をつなぐ市場、資源の独占という三つの思惑が重なっている。

### カード例

| 種類 | カード名 | フレーバーテキスト |
| --- | --- | --- |
| ユニット | 砂海の仲買人 | 持ち主のいない荷？ それは落とし物じゃない。商品だ。 |
| ユニット | 船団長グラナ | この船団は、祖父の代から一度も港に着いたことがない。着く港がないからな。 |
| ユニット | 錨を抱く老船長 | 祖父の代から、一度も港に着いたことがない。この錨を、ようやく下ろせる。 |
| ユニット | 市場の設営係 | 五つの世界の客が、同じ道を通る。店を出さない理由はない。 |
| ユニット | 黒鉄の買い占め屋 | 剣士も学者も、欲しがるものは同じ場所にある。先に押さえた者が値を決める。 |
| スペル（マーケット購入） | 買い付け | 値札が付いた瞬間、それはもう誰のものでもない。払った者のものだ。 |
| スペル | 風の相場 | 今日の風は東向き、一刻あたり銀三枚。 |
| スペル | 初めての港 | 砂が流れない。足元が動かない。こんなに怖くて、嬉しいことはない。 |

## 緑：世界樹を崇拝する使徒たちの国

世界樹と自然を崇める使徒たちの国。ゲーム上の役割はユニット展開。

### 骨子

- 深い森に覆われた国。森の奥にそびえる世界樹を中心に、木々、川、風、獣など自然のすべてを神として崇める
- 信仰を説いて歩く者たちは「使徒」と呼ばれる。使徒が巡礼に出ると、道すがら村人や旅人が次々と列に加わり、行列はどこまでも伸びていく
- 使徒は財も身分も持たない。持ち物は、世界樹から授かった種と杖だけ
- ユニット展開＝巡礼の列に信徒が加わる。仲間が並ぶほど祈りの力が増す

### ヘクサへの動機

古い経典に「灰の地に世界樹の種を植えよ」という一節がある。草一本生えない荒野ヘクサこそ約束の地だと信じ、使徒たちは種を携えて巡礼の列を率いていく。

### カード例

| 種類 | カード名 | フレーバーテキスト |
| --- | --- | --- |
| ユニット | 種を携える使徒 | この種が芽吹く場所まで、私は歩き続ける。 |
| ユニット | 列に加わった農夫 | 畑を置いてきた。なぜかは分からない。ただ、ついて行きたくなった。 |
| ユニット | 世界樹の巫女 | 樹が囁いた。灰の地が、緑を待っていると。 |
| スペル（展開） | 巡礼の呼び声 | 歩き出したときは十人だった。今は、列の終わりが見えない。 |
| スペル | 祈りの輪 | 一人の祈りは風に消える。千人の祈りは、森を動かす。 |
| スペル | 世界樹の加護 | 根はすべて繋がっている。だから私たちも、繋がっている。 |

## 紫：装いが力になる宮廷

身にまとうものすべてに力が宿る宮廷の国。ゲーム上の役割はバフ・変貌。

### 骨子

- 紫の石で築かれた宮殿が幾重にも連なる、宮廷そのものが一つの国になっている世界
- 仮面、宝飾、香水、衣装、称号など、身にまとうものすべてに力が宿る
- 装いを重ねるほど強くなるが、重ねすぎるとその装いに吞まれ、象徴する存在そのものへと成り代わる
- バフ＝装いを重ねる、変貌＝装いに吞まれ、別の存在へ成り代わる

### ヘクサへの動機

空位の王座。宮廷の王座は長く空いたままで、「新たな領地を献上した者が王となる」という古い掟がある。貴族たちは主のいない荒野ヘクサを手に入れようと競い合っている。

### カード例

| 種類 | カード名 | フレーバーテキスト |
| --- | --- | --- |
| ユニット | 末席の令嬢 | まだ誰にも名を覚えられていません。今のところは。 |
| ユニット（変貌後） | 紫冠の女王 | 王座に座ったとき、私の名は消え、国の名だけが残った。 |
| ユニット | 香り売りの侍従 | この香りを嗅いだ方は、みな私の話に頷いてくださる。 |
| ユニット | 荒野を測る廷臣 | 献上する領地は広いほどいい。測り間違えたことにしておきましょう。 |
| スペル（バフ） | 叙爵 | 今日から伯爵。昨日までの自分とは、もう口もきかない。 |
| スペル（バフ） | 宝飾の重ね着け | 一つでは足りない。輝きは、重ねるほど人を黙らせる。 |
| スペル（変貌） | 玉座の噂 | 王が決まるらしい。誰が、とは誰も言わない。 |

## 色同士の関係

五色の全組み合わせで、これまでに出た関係をまとめた。

| 組み合わせ | 関係 |
| --- | --- |
| 赤 × 青 | 剣士は「理屈より一太刀」を信条とし、学生とは話が噛み合わない |
| 赤 × 橙 | 商人は決闘の勝敗に賭け金を募り、立会人を買収しようとする。剣士が最も嫌う相手。剣士が求める黒い鉄を橙が買い占めようとしている |
| 赤 × 緑 | 一人で戦う剣士と大勢で祈る使徒。理解されないが、ときに列に加わる剣士もいる |
| 赤 × 紫 | 貴族は自ら刃を抜かず、決闘の代理人として赤の剣士を雇う。王座争いの裏で赤の刃が動いている |
| 青 × 橙 | 商人は本を高値で買い取りたがるが、書庫は一冊も外に出さない。学生が求める結晶も橙が押さえようとしている |
| 青 × 緑 | 学生は経典を研究対象にしたがるが、使徒は「信仰は読むものではなく歩くもの」と答える |
| 青 × 紫 | 貴族の子女の家庭教師として雇われる上級生もいる。宮廷の陰謀に巻き込まれる者も |
| 橙 × 緑 | 世界樹の枝や葉にも値を付けようとする商人を、使徒たちは静かに拒み続けている |
| 橙 × 紫 | 貴族はヘクサの土地を求めて商人に接近し、商人は売り物でない土地にも値を付けてくる |
| 緑 × 紫 | 装いを重ねる貴族と、何も持たない使徒。宮廷からは「貧しい者たち」と見下されている |
