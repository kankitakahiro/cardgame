# 初期カード一覧 v0.1（マナレシオ付き）

## このドキュメントの前提
- 初期デッキ枚数: 12
- マーケット: 常時5枚公開
- リソース: 毎ターン自動増加マナ（購入とプレイ共通）
- 目標体験: 短期決戦、運7:実力3、理不尽さは抑える

## マナレシオの考え方

### 1. 基準値（Baseline）
- 1マナあたり期待値を `2.0点` とする。
- カード価値点 `ValuePoint` をコストで割って評価する。

式:

`ManaRatio = ValuePoint / (Cost * 2.0)`

### 2. UnitのValuePoint
- 基本: `ATK + HP`
- 追加能力は加点（目安）
  - 速攻: +1.0
  - 守護（相手攻撃を受ける）: +1.0
  - 死亡時1ドロー: +1.5
  - 登場時1ダメージ: +1.0
  - 条件付き強化: +0.5 から +1.0

### 3. SpellのValuePoint
- 直接ダメージ: 1点ダメージ = 1.0
- 回復: 1点回復 = 0.8
- 1ドロー: 2.0
- 1ディスカード: 0.5
- 条件付き追加効果は +0.5 から +1.5

### 4. 判定目安
- 0.85未満: 弱め（シナジー前提）
- 0.85-1.00: 標準
- 1.01-1.10: 強め
- 1.11以上: 要注意（環境を歪めやすい）

## 初期環境での軸（推奨）
- 速攻軸: C002, C005, C009, C013

- 墓地軸: C006, C011, C021, C014

## 初回プレイ前の調整提案
- C003, C004, C006, C012 はレシオ過多なので弱体化候補。
- C023, C024 は弱めなので、演出目的で残すかバフを検討。
- 1マナ帯の高レシオカードが多いと先手ゲー化しやすいため、1マナカードは強さを0.95-1.05付近へ寄せる。

## 弱体化・強化の具体例
- C003: 1/2守護 -> 1/1守護（ValuePoint 3.0、Ratio 1.50）
- C004: 死亡時1ドロー -> 50%で1ドロー（期待値調整）
- C006: 登場時効果を「1ドロー」ではなく「山札上1枚確認」に変更
- C024: 条件達成時3ダメージ -> 4ダメージ（ValuePoint 3.7、Ratio 0.62）

## 実装メモ（Blueprint向け）
- DataTable列候補: CardId, Name, Type, Cost, Atk, Hp, EffectId, Ratio, Tags
- Ratioは調整作業用の補助値として保持し、ゲームロジックの判定には直接使わない。
- マーケット公開5枚は、マーケット山札から不足分を即補充する方式にする。
