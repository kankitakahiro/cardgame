# 次期ルール設計案(ドミニオン×対戦カードゲーム)

実装済みの現行ルール(`docs/game-rules-minimum.md`)のベースとなった設計案。
壁打ちの経緯・ボツ案を残すため、実装後もこのドキュメントは削除せず参照用に
残している。5色×15種のカードリストは
[next-ruleset-cards-v1.md](next-ruleset-cards-v1.md)(サンプルデッキ例も
この中に記載)を参照。カードバランス調整の経緯・実測データは
[next-ruleset-simulation-v1.md](next-ruleset-simulation-v1.md)を参照
(このドキュメントには調整結果を書かない方針)。

## 基本ルール

- 勝利条件: 相手ライフ0
- ライフ: 20
- メインデッキ: 25枚(各プレイヤー個別に構築)
- マナ: 毎ターン+1で自動増加(色マナなし、無色統一)。上限10(現行を維持)
- 手札は自分のメインデッキから引く(通常のTCGと同じ)

## マーケット(購入エリア)

- 共通6枠、早い者勝ちで購入(ドミニオン方式)
- **枠には「出どころ」が紐づいている**。購入すると、その枠の出どころ
  (元々そのカードが並べられた側)の山札からトップ1枚をめくって同じ枠に
  補充する(自滅スパイラル対策として決定。旧案の「買った本人の山札から補充」
  から変更)。
  - マーケットには常に「自分の山札由来3枚+相手の山札由来3枚」が並ぶ状態が保たれる
  - **買う側は「自分の山札を削るか、相手の山札を削るか」を選べる**。同じ強さの
    カードなら相手側の枠から買う方が得(相手の山札を減らせて自分は減らない)
    ため、劣勢側でも自分の首を絞めずに買い物ができる
  - 一方で、両者が「常に相手の枠を優先して買う」を徹底すると、狙いだった
    「自分の山札構成がそのままマーケットの供給源になる」という一体感が薄れ、
    「相手の山札を先に枯らす経済戦」寄りの展開になりやすい。悪い方向では
    ないと思われるが、プレイテストで確認する
- **マーケットの公開情報: 各枠は「どちらの山札由来か」を表示する**(決定済み)。
  上記の補充ルール変更により、これは単なる情報戦の材料に留まらず、
  「どちらの枠から買うか」を判断するための必須情報になった。
  なお山札の並び順自体は最後までランダムなので、実際には「購入のたびに
  ランダムな1枚のサンプルが見える」程度に留まり、終盤に相手の残り山札が
  丸見えになるほどの情報公開にはならない見込み。
- **試合開始時のマーケット初期化(決定済み)**: 両者が自分の山札トップから
  3枚ずつ(計6枚)同時に公開してマーケットへ並べる。この3枚がそれぞれの
  出どころタグの初期値になる。両者とも実質22枚残りの山札で試合を始める
  ことになる点は許容する
- 実装メモ: マーケット補充で山札が0枚の状態から引こうとした場合も、通常の
  ドローと同じ山札切れ処理(捨て札シャッフル+ライフ減少)を発動させる必要がある

## 山札切れペナルティ

- 捨て札をシャッフルして山札に戻す + ライフ減少(即死にしない)

## 色システム(5色+無色)

| 色 | 軸 | キーワード | パッシブ(条件発動、報酬は共通でコイン+1・1ターン1回) |
|---|---|---|---|
| 赤 | 速攻/バーン | 疾駆: 最初に出したユニットは即攻撃可 | このターン3枚目のカードをプレイしたとき |
| 橙 | 購入加速(本作の核) | 先物: 次の購入が割引 | このターン最初の購入をしたとき |
| 緑 | ユニット/物量/守護/回復 | 庇護: このユニットが攻撃を強制的に引き受ける | 自分のターン開始時、場にUnitが3体以上いれば |
| 青 | コントロール(除去+追放統合) | 封印: 対象を追放、墓地にも行かず再利用不可 | このターン2回目のドローをしたとき |
| 紫 | 強化/変容 | 変貌: 条件達成で上位カードに置き換わる | 変貌が成功したとき |
| 無色 | どの色にも属さない汎用カード | 無し | 無し(しきい値のカウント対象外) |

- **パッシブの統一(決定済み)**: 元は色ごとにバラバラの効果(疾駆付与/割引/
  攻撃力アップ/マナ還元→ドロー/ドロー)だったが、「パッシブの説明が
  分かりにくい」「マナが増えるのはおかしい」というフィードバックを受け、
  5色とも報酬を「コイン+1(1ターン1回)」に統一し、発動条件だけを色ごとに
  変える形に整理した。コインは通常のマナ(プレイ/購入共通)とは別枠の、
  マーケットでの購入専用の資源で、ターンをまたいでも減らず貯まり続ける
  (docs/game-rules-minimum.md「色ガイド」参照)

- **無色グループ(決定済み)**: 旧ルール(初期デッキ12枚時代)で作った24種
  (`initial-cards-v0.1.md`、`BuildLegacyCards()`)を、新規デザインせずそのまま
  「無色」グループとして流用する。どの色のデッキにも自由に混ぜられるが、
  混ぜた分だけ主軸の色のしきい値(17/25)到達に使える母数が減るため、
  「無色に逃がすか、色に全振りしてパッシブを取るか」というトレードオフが生まれる
- パッシブ発動しきい値: デッキ25枚中**17枚以上**(決定済み。当初13枚から、
  「緩い」というフィードバックを受けて引き上げた)。17×2=34>25のため、
  2色同時達成は数値上不可能。15種類全てを1枚ずつ揃えるだけでは足りず、
  必ずどれか2種類以上を複数枚採用する構成が要求される。

### 回復について

- 緑をメイン、紫にごく少量のみ
- 赤・橙・青には意図的に持たせない(色ごとの役割分担を保つため)
- 1枚あたりの回復量は控えめ(目安1〜3点)
- 無条件回復ではなく「守護時」「変貌成功時」など行動と紐づける

### 変貌の詳細ルール

- 変貌先カードの色は、変貌元カードと必ず同じにする
- 変貌は「場にいる間だけ」有効な状態。死亡(墓地行き)・手札に戻す効果・
  山札に戻す効果など、理由を問わず場を離れたら元のカードに戻る
  (どの離れ方でも同じ扱いに統一し、実装を単純にする)

### 色同士の関係性(メタゲーム)

- 赤(速攻) vs 緑(回復/守護): 典型的なアグロ対コントロールの構図
- 青(封印)は墓地活用系への天敵として機能
- 橙の「買うほど山札が減る」自己ブレーキは、マーケットの補充ルール変更
  (出どころの山札から補充)により「相手の枠から買えば自分は減らない」形に
  緩和された。買う側の選択次第で自分にも相手にもリスクを向けられる、
  経済戦寄りの軸になった

## ボツ・保留になったアイデア

- 自分専用マーケットの事前構築(6種選定) → 共通マーケット+早い者勝ちに変更したため保留
- 7色構成(黄: ドロー、藍: 追放を独立させる案) → 5色に統合、黄は廃止、藍は青に統合
- 墓地活用軸 → 山札切れで捨て札が山に戻る仕様と衝突するため独立した色にしない、紫に薄く残す程度
- マーケットの3枚めくり方式 → 1枚ずつの補充に変更したため不採用

## 壁打ちで決定した事項

| 項目 | 決定内容 |
|---|---|
| 戦闘の当たり方 | 現行どおり、1体指定攻撃。庇護(緑)持ちがいれば強制的にそちらが対象(既存のGuard自動ターゲット実装をそのまま踏襲) |
| マナ上限 | 10(現行維持) |
| カードタイプ「永続」 | 場に残るがユニット枠を使わず、攻撃も被攻撃もしない継続効果カード(MTGのエンチャントに近い)。除去は封印(青)等の対象指定効果でのみ可能 |
| パッシブしきい値 | 17/25で確定(2色同時達成は数値上不可能。当初13/25から、実装後のプレイ感触で「緩い」と判断し引き上げた) |
| マーケット公開情報 | 出典(どちらの山札由来か)を表示する |
| デッキ内の同名カード重複 | 3枚まで可 |
| カード実枚数の目安 | 1色あたり15種類(5色合計75種)からスタート。加えて無色24種(旧ルールからの流用)を6つ目のグループとして併用 |
| 先手/後手調整 | 後手にドロー1枚+コイン1+一時マナ1(最初の1ターンのみ、Hearthstoneの「The Coin」相当)を追加。加えて先攻1ターン目は攻撃禁止(疾駆Unitも含む)。3000戦シミュレーションで先攻73.9%勝という致命的な偏りが判明し段階的に強化した結果、先攻59.7%勝まで改善(まだ完全な対等ではないが大幅に改善。永続マナ加速は後攻82.7%勝と過剰補正したため不採用。docs/next-ruleset-simulation-v1.md「第12回」参照) |
| 1ターンの購入回数制限 | 制限なし(現行のプレイ回数制限なしと同じ考え方。マナという共通リソースが自然に頭打ちにするため、専用の制限ルールは不要) |
| マーケットの初期化 | 両者が自分の山札トップから3枚ずつ(計6枚)同時に公開して並べる |
| マーケットの補充元 | 枠の出どころ(元々並べた側)の山札から補充する(買った本人の山札からではない)。自滅スパイラル対策 |
| 早い者勝ち購入 | 特別な追加ルールではなく、交互ターン制の帰結として確定(手番側が先にマーケットを見られるだけ) |
| 変貌の色 | 変貌先は変貌元と必ず同じ色 |
| 変貌の永続性 | 場にいる間だけ有効。理由を問わず場を離れたら元のカードに戻る |

## 今後決めていくこと(未解決)

- (現時点でルール面の大きな未解決事項は無し。マーケット補充ルールの変更が
  自滅スパイラル対策を兼ねたため、関連する論点はまとめて決定済みに移動した)
- **「常に相手の枠から買う」が支配戦略化しないか**: マーケット補充ルール変更
  (出どころの山札から補充)により、同じ強さのカードなら相手の枠から買う方が
  一方的に得になる。両者がこれを徹底した場合に、狙っていた「自分の山札構成が
  マーケットの供給源になる」体験が薄れすぎないか、引き続きプレイテストで確認する
- カードバランスの調整状況(各色の強さ・ナーフ/バフの経緯・実測勝率)は
  [next-ruleset-simulation-v1.md](next-ruleset-simulation-v1.md)で一本化して
  管理している。このドキュメントには転記しない。
