# 対戦ルール仕様(現行実装)

`CardGame/Source/CardGame/` の実装(`ACGGameMode`/`ACGPlayerState`)に対応する、
現行のルール仕様。設計・拡張方法は [architecture.md](architecture.md)、
カード一覧・バランスは [initial-cards-v0.1.md](initial-cards-v0.1.md) を参照。

## 対戦条件

- 1対1(Side0=人間、Side1=AI固定。`UCGAIOpponent`が自動で行動する)
- 先攻後攻はランダム

## 初期設定

- デッキ枚数: 12(重複なし、24種のカードから選ぶ。デッキ構築画面
  `L_DeckBuilder`で編成し、`UCGGameInstance`経由で永続化される)
- 初期ライフ: 20
- 初期手札: 5枚
- 手札上限: 10枚(超える分はドローした瞬間に捨て札へ送る)
- マーケット: 常時5枚公開。購入/プレイどちらかで減った分は残りのプールから
  自動補充される
- マナ: プレイと購入で共通のリソース。ターン開始ごとに最大マナが+1され、
  その分だけ全回復する(上限10)

## ターン構造

1. Draw Phase: 1枚ドロー、マナ最大値+1して全回復、自分の場のユニットの
   攻撃可否をリセット
2. Main Phase: カードのプレイ、マーケットからの購入、攻撃を任意の順・
   任意の回数行える(1ターン1回だけ、という制限は現行実装には無い)
3. End Phase: 常在効果(例: 市場の仲買人)を解決してターン終了、相手へ交代

## プレイ・攻撃のルール

- コストが足りないカードはプレイ/購入不可
- 対象選択が必要な効果は単一対象のみ。UIでの手動ターゲット選択は無く、
  「相手に守護(Guard)がいれば必ずそちらへ、いなければ相手リーダーへ」という
  自動選択ルールで解決する(人間側UI・AI側とも同じルールを使う)
- 守護(Guard)を持つユニットがいる場合、攻撃は必ずそのユニットが対象になる
- 各ユニットは登場したターンは攻撃不可(速攻(Haste)を持つ場合を除く)

## キーワード(タグ)

- `Haste`(速攻): 登場したターンでも攻撃できる
- `Guard`(守護): このユニットがいる間、相手の攻撃は必ずこのユニットへ向く

## 勝利条件 / 敗北条件

- 相手ライフを0以下にすると勝利
- 自分のライフが0以下になると敗北
- ドロー時にデッキが0枚だと敗北(山札切れ負け)
- 両者同時に敗北条件を満たした場合は引き分け

## カード種別

- Unit(場に出るカード): 登場時効果、常在効果、死亡時効果を持てる
  (実装方法は architecture.md の「カード効果ディスパッチ」参照)
- Spell(即時効果): プレイした瞬間に効果を解決し、そのまま捨て札へ
