# 対戦ルール仕様(現行実装)

`CardGame/Source/CardGame/` の実装(`ACGGameMode`/`ACGPlayerState`)に対応する、
現行のルール仕様。キーワード(タグ)の定義一覧は[keywords.md](keywords.md)、
HUDのアニメーション・視覚フィードバックは[presentation.md](presentation.md)、
世界観・フレーバーは[カードゲーム 世界観・フレーバー設定.md](<カードゲーム 世界観・フレーバー設定.md>)、
カード一覧は[next-ruleset-cards-v1.md](next-ruleset-cards-v1.md)、実装方法は
[architecture.md](architecture.md)を参照。

## 対戦条件

- 1対1。オフラインでは Side0=人間、Side1=AI固定(`UCGAIOpponent`が自動で行動する)。
  オンライン対戦(ホスト/ゲストの2人対戦)にも対応している
  (下記「オンライン対戦」参照)
- 先攻後攻はランダム。後手には次の3つのハンデを与える(先攻有利の緩和):
  初期手札の後にもう1枚ドロー、コイン+1(恒常)、最初の1ターンだけ通常マナ+1
- 先攻1ターン目は攻撃を一切禁止する(疾駆Unitも含む)。上記のハンデだけでは
  先攻の「毎ラウンド半ターン早く攻撃できる」複利効果を相殺しきれなかったため
  追加した(自己対戦シミュレーションで先攻優位を計測して段階的に調整した結果)

## 初期設定

- デッキ枚数: 25(同名カード3枚まで重複可、5色76種(紫のみ16種、他4色は
  15種ずつ)+無色24種の計100種の
  カードプールから選ぶ。デッキ構築画面`L_DeckBuilder`で編成し、
  `UCGGameInstance`経由で永続化される)
- 初期ライフ: 20(試合を長引かせる狙いで一時30に引き上げたが、その後の
  パッシブ再設計を経てユーザーの判断で20に戻した)
- 初期手札: 5枚(後手は+1枚、上記参照)
- 手札上限: 10枚(超える分はドローした瞬間に捨て札へ送る)
- マーケット: 常時6枠公開(両陣営の山札から3枚ずつ試合開始時に並べる)。
  各枠は「出どころ(元々並べた側の山札)」を保持し、購入されるとその枠は
  **出どころ側の山札トップ**から補充される(買った本人の山札からではない。
  自滅スパイラル対策として決定)
- 購入したカードは、手札に加えるか山札の一番下に送るかをその場で選ぶ
  (`ECGChoiceType::BuyDestination`)。手札上限(10枚)に達していても、山札下へ
  送る狙いで購入自体は可能
- マナ: プレイと購入で共通のリソース。ターン開始ごとに最大マナが+1され、
  その分だけ全回復する(上限10)
- 色システム: カードは赤/橙/緑/青/紫の5色、またはどの色にも属さない「無色」
  (旧24種、`initial-cards-v0.1.md`)のいずれかを持つ。デッキ25枚中17枚以上を
  占める色は「発動中」となり、該当色のパッシブ効果が有効になる。無色カードは
  どの色のデッキにも自由に混ぜられ、この17枚のカウントには入らない(入れた分
  だけ他の色のカウントできる母数が減る)。詳細は下記「色ガイド」

## 山札切れペナルティ

- 山札が0枚の状態でドローしようとした場合、即敗北にはせず、捨て札を
  シャッフルして山札に戻したうえでライフを3減らす
- 捨て札も0枚(封印等で大半を失った極端なケース)なら敗北する

## ターン構造

1. Draw Phase: 1枚ドロー、マナ最大値+1して全回復、自分の場のユニットの
   攻撃可否をリセット。場のUnitが持つ「ターン開始時」常在効果(ドロー/
   購入割引付与等)や変貌の進行度判定もここで行う
2. Main Phase: カードのプレイ、マーケットからの購入、攻撃を任意の順・
   任意の回数行える(1ターン1回だけ、という制限は現行実装には無い)
3. End Phase: 常在効果(購入時ドロー等)を解決してターン終了、相手へ交代

## プレイ・攻撃のルール

- コストが足りないカードはプレイ/購入不可
- マーケットで、現在のコイン+マナで届かないカードは薄く表示する(クリック
  自体は禁止しないが購入は拒否される。表示の詳細は
  [presentation.md](presentation.md)「マーケットの購入可否表示」参照)
- 対象選択が必要な効果・攻撃は、専用モーダルを使わず画面上のカード/ボタンを
  直接クリックして選ぶ(手札から1枚選ぶ/墓地から1枚選ぶ/敵ユニットか顔面を
  選ぶ/山札の一番上を残すか送るか選ぶ、等。詳細は architecture.md
  「選択待ち(PendingChoice)の仕組み」)。AI側もこの機構を経由せず、同じ
  判断ロジックをその場で同期的に適用する
- 守護(Guard)を持つユニットがいる場合、攻撃は必ずそのユニットが対象になる
- 各ユニットは登場したターンは攻撃不可(速攻(Haste)を持つ場合を除く)

## 行動ログ

「CPUと対戦したときに何をされたのか分からない」というフィードバックへの
対応。カードのプレイ・マーケットでの購入・攻撃・フィニッシャーの登場を記録し、
画面下部の「行動ログ」ボタンでいつでも開いて見返せる。詳細は
[presentation.md](presentation.md)「行動ログ」を参照。

## キーワード(タグ)

6つのキーワード(疾駆/分身/庇護/封印/変貌/先物。庇護は紫に多いが専用ではなく、
他色に例外的に付くこともある)の定義一覧は[keywords.md](keywords.md)を参照。

## 色ガイド(5色+無色)

各色のキーワード定義は[keywords.md](keywords.md)、世界観・フレーバーは
[カードゲーム 世界観・フレーバー設定.md](<カードゲーム 世界観・フレーバー設定.md>)
を参照(下表の「キーワード」「世界観」列はそこへのポインタのみ)。

- しきい値: デッキ25枚中**17枚以上**でパッシブ発動(2色同時達成は数値上不可能)
- **パッシブは5色とも共通の報酬「コイン+1(1ターン1回)」で統一されており、
  発動条件だけが色ごとに異なる**(以前は色ごとにバラバラの効果だったが、
  「パッシブの説明が分かりにくい」「マナが増えるのはおかしい」という
  フィードバックを受けて整理した)。コイン(`PurchaseMana`)は通常のマナ
  (プレイにも購入にも使える)とは別枠の、**マーケットでの購入にしか使えない
  専用の資源**。通常のマナと違ってターンをまたいでも減らず、使うまで
  貯まり続ける。購入時はコインを優先して使い、足りない分を通常のマナから払う
- 回復は緑がメイン、紫にごく少量のみ。赤・橙・青には意図的に持たせない
- 回復量は控えめ(目安1〜3点)、無条件ではなく行動(被弾時/変貌成功時など)に紐づける
- 無色(下記)はどの色にも属さないニュートラルなグループで、パッシブや
  しきい値の対象外。5色と組み合わせて自由にデッキへ混ぜられる

### 赤 — 速攻/バーン

| 項目 | 内容 |
|---|---|
| 軸 | 速攻でユニットを並べて攻め切る、直接ダメージで押し切る |
| キーワード | 疾駆([keywords.md](keywords.md)参照) |
| 世界観 | 決闘の国。速攻=先に抜く、バーン=赤熱した刃の一閃([世界観・フレーバー設定](<カードゲーム 世界観・フレーバー設定.md>)「赤:決闘の国」) |
| パッシブ(17枚〜) | このターン3枚目のカードをプレイしたとき、コイン+1(1ターン1回) |
| 回復 | 無し |
| 代表カード | R03 焼印の斥候(1c 1/1疾駆)、R14 総攻めの狼煙(場のUnit数×2点の一撃) |
| メタゲーム上の立ち位置 | 緑(分身/回復)に対してはアグロ対コントロールの構図で不利になりやすい |

### 橙 — 購入加速(本作の核)

| 項目 | 内容 |
|---|---|
| 軸 | マーケットでの購入を軸にしたテンポ/経済アドバンテージ |
| キーワード | 先物([keywords.md](keywords.md)参照) |
| 世界観 | 金砂の海を渡る商船の世界。マーケット購入=積荷を買い付けて船団に加える([世界観・フレーバー設定](<カードゲーム 世界観・フレーバー設定.md>)「橙:金砂の海を渡る商船の世界」) |
| パッシブ(17枚〜) | このターン最初の購入をしたとき、コイン+1(1ターン1回) |
| 回復 | 無し |
| 代表カード | O07 即断の商談(即時購入+手札化)、O15 独占商人(マーケットから無料回収) |
| メタゲーム上の立ち位置 | マーケット補充ルール(出どころの山札から補充)により、「相手の枠から買えば自分は減らない」という選択を握れる経済戦寄りの軸 |

### 緑 — ユニット/物量/分身/回復

| 項目 | 内容 |
|---|---|
| 軸 | 頭数を並べて盤面を制圧しつつ、分身で数を増やし回復で粘る |
| キーワード | 分身([keywords.md](keywords.md)参照)。以前は庇護だったが、庇護は紫の護衛カードへ移した |
| 世界観 | 世界樹を崇拝する使徒たちの国。ユニット展開=巡礼の列に信徒が加わる、分身=同じ教えを説く仲間が増えていく([世界観・フレーバー設定](<カードゲーム 世界観・フレーバー設定.md>)「緑:世界樹を崇拝する使徒たちの国」) |
| パッシブ(17枚〜) | 自分のターン開始時、場にUnitが3体以上いればコイン+1(1ターン1回) |
| 回復 | メイン担当。G06/G12/G15が回復源 |
| 代表カード | G05 群れの誕生(1/1を2体展開)、G15 万象の守り神(分身+回復) |
| メタゲーム上の立ち位置 | 赤(速攻)に対してはアグロ対コントロールの構図で有利になりやすい(要再検証: 以前は庇護の身代わり効果が主因だったため、分身への変更後の実際の勝率はシミュレーションで未確認) |

### 青 — コントロール(除去+追放統合)

| 項目 | 内容 |
|---|---|
| 軸 | 相手の脅威を対象指定で確実に排除し、盤面をコントロールする |
| キーワード | 封印([keywords.md](keywords.md)参照) |
| 世界観 | 書庫と学生の国。除去=書物に記された術で相手を封じる([世界観・フレーバー設定](<カードゲーム 世界観・フレーバー設定.md>)「青:書庫と学生の国」) |
| パッシブ(17枚〜) | このターン2回目のドローをしたとき、コイン+1(1ターン1回)。通常のターン開始時ドローが1回目になるため、B05等の追加ドロー元と組み合わせると発動しやすい |
| 回復 | 無し |
| 代表カード | B06 深淵の封印(コスト制限なしの単体除去)、B13 叡智の大魔導(パワー3以下を封印できる封印持ちUnit)、B14 終焉の裁定者(毎ターン自動封印) |
| メタゲーム上の立ち位置 | 墓地活用系(紫の一部)への天敵 |

### 紫 — 強化/変容

| 項目 | 内容 |
|---|---|
| 軸 | ユニットを育てて条件達成で上位カードへ変貌させる |
| キーワード | 変貌([keywords.md](keywords.md)参照) |
| 世界観 | 装いが力になる宮廷。バフ=装いを重ねる、変貌=装いに呑まれ別の存在へ成り代わる([世界観・フレーバー設定](<カードゲーム 世界観・フレーバー設定.md>)「紫:装いが力になる宮廷」) |
| パッシブ(17枚〜) | 変貌が成功したとき、コイン+1(1ターン1回。複数体が同時に変貌しても1回まで) |
| 回復 | ごく少量のみ。P06の変貌先P06T(変貌成功時に味方リーダーを1回復)の1枚だけに絞ってある |
| 代表カード | P01 無垢の使い魔→P01T 若き賢者(軽い条件)、P15 不完全な神→P15T 真なる姿(毎ターン50%の重い条件+登場時2点) |
| メタゲーム上の立ち位置 | 変貌先も色は変貌元と同じ(紫)。場を離れると変貌が解けるため、除去耐性は無い |

### 無色 — どの色にも属さないニュートラル

| 項目 | 内容 |
|---|---|
| 軸 | 特定の色の強み・パッシブに依存しない汎用カード。どのデッキにも混ぜられる |
| キーワード | 無し(疾駆/分身/庇護/封印/変貌/先物のいずれも持たない) |
| パッシブ(17枚〜) | 無し(無色はしきい値のカウント対象外のため、無色だけで17枚集めてもパッシブは発動しない) |
| 回復 | あり(色ごとの役割分担の対象外のため、他の無色カードと同様に個別の効果として存在) |
| 出典 | 旧ルール(初期デッキ12枚時代)で作った24種(`initial-cards-v0.1.md`)をそのまま流用。`UCGCardDatabase::BuildLegacyCards()` |
| メタゲーム上の立ち位置 | 特定の色の一員にはならないため、5色いずれのデッキにも枚数を気にせず足せる「つなぎ」の枠。ただし混ぜた分だけ主軸の色のしきい値(17/25)到達に使える母数が減る |
| 現状の懸念 | 旧ルール(マーケット常時5枚・初期デッキ12枚)を前提に数値設計されたままで、次期ルールのマナレシオ計算・自己対戦シミュレーションには含めていない。5色と混在させたときの強さは未検証 |

### 色ごとの一目比較

| 色 | 得意なこと | 苦手なこと | 除去耐性 |
|---|---|---|---|
| 赤 | 短期決戦、面制圧からの詰め | 長期戦、盤面を止められると失速 | 無し |
| 橙 | 手数・経済アドバンテージ | 単体の質でのゴリ押し | 無し |
| 緑 | 持久戦、盤面の量と硬さ | 除去(青)に一体ずつ剥がされる | 無し(分身も条件成立前に除去されると発動しない) |
| 青 | ピンポイントの脅威排除 | 自分から盤面を作る手段が薄い | ― |
| 紫 | 長期的な質の向上 | 変貌前に除去されると投資が無駄になる | 護衛(庇護)が変貌前の投資を守る。変貌後は場を離れれば解ける |
| 無色 | どのデッキにも混ぜられる汎用性 | 色のパッシブが乗らない、しきい値の母数を圧迫する | カードによる(封印等の専用キーワードは無し) |

上記の表は色の設計意図(狙った役割分担)を表すもので、自己対戦シミュレーションで
計測した勝率そのものではない。個別カードのナーフ/バフの経緯は
[next-ruleset-cards-v1.md](next-ruleset-cards-v1.md)の各カード表の「ナーフ」列を
参照。

## フィニッシャー

各色に1枚ずつ、専用の条件を満たすと**手札・マナを消費せず自動的に場へ登場する**
固有Unit(コスト10)を用意している。デッキがその色の`ActiveColors`(しきい値
17/25発動中)に含まれていない場合は登場しない。1試合中、1色につき1回のみ
(`ACGPlayerState::FinishersSpawned`で管理)。判定は`NotifyStateChanged()`の
たびに行う(`ACGPlayerState::CheckAndSpawnFinisher()`)。カード自体もカード
UI上で金色の特別なデザイン(枠線・カード名の色)で表示される。

先攻優位の緩和策として、**後手は下表の必要数を一律-2**した状態で判定される
(`ACGPlayerState::bWentSecond`。ドロー+1/コイン+1/一時マナ+1と同じ
「後手にハンデを与える」方針の延長。-1では先攻61.1%までしか下がらず、
-2で先攻56.1%まで改善した)。下表は先攻側(通常)の必要数。

| 色 | 条件 | フィニッシャー |
|---|---|---|
| 赤 | 味方Unitが累計10体死亡 | 紅蓮の覇王(疾駆 8/8) |
| 橙 | マーケットから累計10枚購入 | 黄金の帝王(5/5、登場時マーケットのUnitを3枚、選んでタダで場に出す) |
| 青 | カードを累計18枚ドロー | 深淵の裁定者(6/6、登場時敵Unitをすべて追放) |
| 緑 | 場にUnitが8体並ぶ | 大地の化身(4/4、登場時味方Unitすべてを+1/+1) |
| 紫 | Unitが累計5体変貌 | 変貌の女神(5/5、場にいる限り新しく登場した味方Unitは変貌条件を無視して即座に変貌) |

条件の達成度(死亡数/購入数/ドロー数/変貌数)は試合単位でリセットされる
マッチ限定カウンタ(`ACGPlayerState::AlliesDiedThisMatch`等)で管理している。

## オンライン対戦

ホスト/ゲストの2人でのオンライン対戦(サーバー権威、`SteamSockets`経由の
インターネット越し接続にも対応)を実装済み。ルール自体はオフライン(vs AI)と
共通で、`ACGGameMode`/`ACGPlayerState`のロジックをそのまま両モードで使い回す。
設計・実装の詳細は[online-play-design.md](online-play-design.md)と
[architecture.md](architecture.md)「オンライン対戦移行時の実装メモ」を参照。

## 勝利条件 / 敗北条件

- 相手ライフを0以下にすると勝利
- 自分のライフが0以下になると敗北
- 両者同時に敗北条件を満たした場合は引き分け
- 決着時の演出(「勝利!」/「敗北...」バナー、クリックでロビーに戻る導線)は
  [presentation.md](presentation.md)「勝敗演出」を参照

## カード種別

- Unit(場に出るカード): 登場時効果、常在効果、死亡時効果を持てる
  (実装方法は architecture.md の「カード効果ディスパッチ」参照)
- Spell(即時効果): プレイした瞬間に効果を解決し、そのまま捨て札へ
- Permanent(永続): 次期ルールで追加した型。場に残るがユニット枠を使わず
  攻撃も被攻撃もしない継続効果カード(該当カードは現時点で未作成)
