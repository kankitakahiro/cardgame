# 最小ルール仕様（ローカル対戦プロトタイプ）

## 目的
短期間で遊べるプロトタイプを作るため、ルールを最小化する。

## 対戦条件
- 1対1
- ローカル対戦
- 先攻後攻はランダム

## 初期設定
- デッキ枚数: 20
- 初期手札: 5
- 初期ライフ: 20
- 手札上限: 10

## ターン構造
1. Draw Phase
  - 1枚ドロー
2. Main Phase
  - カードをプレイ可能
3. End Phase
  - ターン終了

## プレイ制限（初期）
- 1ターンに1回だけカードをプレイ可能
- コストが足りないカードはプレイ不可
- 対象選択が必要なカードは単一対象のみ

## 勝利条件
- 相手ライフを0以下にする

## 敗北条件
- 自分ライフが0以下になる
- ドロー時にデッキが0枚（山札切れ負け）

## まず実装するカード種
- Unit（場に出るカード）
- Spell（即時効果）

## まず実装する効果種
- 単体ダメージ
- 単体回復
- カードドロー

## 将来拡張（後回し）
- スタック処理
- 連鎖効果
- 置換効果
- 永続効果レイヤー
- オンライン同期
