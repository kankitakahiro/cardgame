# カードゲーム開発メモ

## 最初のマイルストーン
- ルール定義（ターン、勝利条件、デッキ枚数）
- カードデータ定義（DataTable or DataAsset）
- 最小対戦ループ（ドロー、プレイ、ターン終了）
- UIプロトタイプ（手札、場、山札、墓地）

## 技術方針メモ
- 実装方式: Blueprint中心で開始し、重い部分をC++へ移行
- UEバージョン: 5.8
- 対戦方式: 未決定（ローカルのみ / オンライン対応）

## C++へ移行する目安
- 毎フレーム実行される重い処理（大量ループ、探索、評価計算）
- AIやカード効果解決など、分岐が多くテストしにくい共通ロジック
- 複数Blueprintで重複し始めた共通処理
- プロファイラでボトルネックが確認できた処理

## 当面の実装順
1. Blueprintでゲームループを先に完成させる
2. 計測して重い箇所を特定する
3. 該当部分のみC++化してBlueprintから呼び出す
